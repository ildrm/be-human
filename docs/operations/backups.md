# Backup strategy

Run `scripts/backup.ps1 -Destination <absolute-backup-file>` on a trusted operator host. Store the custom-format dump encrypted in immutable off-site storage with tested retention. The current export implementation stores JSON in PostgreSQL; no private object storage is used by the application. If object storage is introduced, its backup and restore must be designed and tested separately. Keep keys, database backups, and application secrets in separate failure domains; document key-loss consequences.

Use `scripts/restore-verify.ps1 -Backup <file>` regularly. It restores into an isolated `be_human_restore_verify` database, checks the migration count, then removes the verification database. On 2026-09-25, a manual custom-format dump and restore inside an isolated test container confirmed five migration records. The script itself was not exercised. Production exercises must also check row counts, ownership isolation, RPO/RTO, and application startup against the restored copy.
