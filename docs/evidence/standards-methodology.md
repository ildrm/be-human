# Standards methodology

1. Prefer primary authoritative sources: international bodies, current government guidance, validated instrument owners, and peer-reviewed consensus/systematic evidence.
2. Record authority, URL/DOI, publication date, version, effective dates, population, jurisdiction, unit, classification, strength, limitations, contraindications, license, and last verification.
3. Separate legal requirements, clinical/professional restrictions, safety constraints, population guidance, contextual benchmarks, personal baselines, and preferences.
4. Resolve precedence: professional restriction → legal/safety restriction → accessibility requirement → applicable population guideline → contextual benchmark → personal optimization.
5. Publish only after scientific review. New versions do not mutate historical calculations. Retired versions remain reproducible but are excluded from new recommendations.
6. If no verified standard exists, return that fact; do not ask AI to invent one.

Verification dates record review, not an assertion that a source will never change. A scheduled review must revisit both source status and applicability logic.
